==================================================
BUG TO FIX
==================================================

The following behavior has been observed:

A user has an existing long-term memory containing information such as:

"I am preparing for an SDE role and learning C++ from scratch."

Later, the user asks:

"Do you remember what I am preparing for?"

The agent sometimes responds that it has no saved memory, even though the relevant memory exists in the user's Firestore/Qdrant memory system.

The current conversation may also contain relevant information.

The desired behavior is:

CURRENT CHAT CONTEXT + RELEVANT LONG-TERM MEMORY
                    ↓
                  AGENT
                    ↓
                 GEMINI
                    ↓
             correct response
